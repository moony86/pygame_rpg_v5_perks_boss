BLUECUBE - WINDOWS DEVELOPMENT DEMO
Developer: moony86

Run BlueCube.exe. No Python installation is required on the player's machine.
Keep the ENTIRE BlueCube directory, including _internal, next to the EXE.
Do not copy BlueCube.exe alone. This is an onedir build, not a onefile archive.

WASD: move. Mouse: aim/fire. Space: release to dash. E: interact.
Escape: pause. Tab: detailed stats/map.
In the sanctuary approach a keeper and press E. Shop options support mouse
clicks or number keys. The northern gate starts a challenge after confirmation.

Settings are saved in the user's local BlueCube application data directory,
not in the distribution folder. Do not overwrite the _internal folder with
files from a different build; replace/copy the complete distribution instead.

This is a test build. Read CREDITS.md and RIGHTS_AND_NOTICES.md; older asset
licenses still need review before a public/commercial release.
build-manifest.json records build identity and file hashes.
smoke-test.json records automated resource validation, not a human playtest.
