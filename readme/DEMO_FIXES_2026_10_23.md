## إصلاحات اللعب

- إطلاق المسدس يعتمد ShootingSystem وحده؛ لم يعد cooldown السلاح يمنع تأثير Fire Rate.
- منع تشغيل صوت الإطلاق مرتين من المسار المباشر والحدث في Game.
- إصلاح KeyError لجمع العلاج وتجميد الوقت، والحفاظ على عدم تكرار المكافأة.
- E لا يجمع لوت الغرفة أثناء القتال أو بعيداً عن باب صالح؛ التجميع النهائي مرتبط بخروج متاح.
- بعد إخلاء الغرفة يبدأ اللوت المتبقي الانجذاب للاعب. إذا اختار الخروج فوراً يجمع الباقي بأمان قبل الانتقال؛ لا توجد محاكاة انتقال متحركة بين الغرف بعد.
- مهلة الاستعداد في بداية الغرفة لم يعد مسار تسريع الظهور يتجاوزها.
- Synergy تتطلب تطابق tags المحددة؛ لم يعد offense وحده ينتج شارة CRIT وهمية.
- إعادة الجولة تصفر مؤقت إطلاق النار والاختيارات القديمة وحالة ضغط Dash.
- Return في Pause يعيد للقائمة؛ Esc يستأنف وQ يخرج كما سابقاً.
- منع خصم ثمن علاج الصحة الكاملة أو مهارة مجهزة بالفعل.
- إعدادا aim_assist وscreen_shake يحترمهما النظامان المعنيان.

- أبواب الإخلاء تحمل أسماء الوجهات، مع منع خروج النص خارج الشاشة.
- إرشاد بدء دائم في Hub وعنوان فوق Gatekeeper، وتلميح للتحكم عند بداية الغرف.
